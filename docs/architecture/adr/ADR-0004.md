# ADR-0004 — Framework de orquestación del agente: LangGraph

| Campo       | Valor                          |
|-------------|--------------------------------|
| Estado      | Aceptado                       |
| Fecha       | 2026-06-23                     |
| Autores     | Victor Manuel Lugo Ramirez     |

## Contexto

La Fase 3 requiere un agente que:
1. Llame herramientas (tools) de forma iterativa (propensidad → EV → oferta).
2. Se suspenda a mitad de ejecución para pedir aprobación humana en clientes de alto valor.
3. Reanude la ejecución tras recibir la decisión.
4. Mantenga historial de mensajes y estado de sesión (checkpointing).

## Opciones evaluadas

| Opción | Ventajas | Desventajas |
|--------|----------|-------------|
| **LangGraph** | Grafo cíclico nativo; `interrupt()` y `Command(resume=...)` para HITL; `MemorySaver` out-of-the-box; streaming por nodo; typing con TypedDict | Curva de aprendizaje; overhead para agentes simples |
| LangChain LCEL | Menos boilerplate para chains lineales | No soporta ciclos (tool → LLM → tool); HITL requiere hacerlo a mano |
| CrewAI | Buen soporte multi-agente | Overkill para un único agente; menos control fino sobre el estado |
| Orquestación manual | Control total; sin dependencias extra | Re-implementar checkpointing, streaming e interrupt desde cero |

## Decisión

**LangGraph** — por las siguientes razones:

1. **`interrupt()` nativo**: La suspensión condicional del grafo (cuando EV > umbral)
   es la feature más difícil de implementar a mano. LangGraph la provee en tres líneas.

2. **Grafo cíclico**: El loop ReAct (analyst → tools → analyst) requiere ciclos;
   LCEL los prohíbe explícitamente.

3. **Checkpointing con `MemorySaver`**: El estado del agente (mensajes, propensidad,
   CLTV, EV, aprobación) persiste entre la interrupción y la reanudación sin código extra.

4. **Interfaces tipadas (`TypedDict`)**: El `AgentState` documenta con tipos
   exactamente qué viaja por el grafo; se valida en tiempo de ejecución.

5. **Streaming por nodo**: Listo para exponer via API (Fase 4) con `astream_events`.

## Consecuencias

- **Positivo**: El HITL, los ciclos y el checkpointing están cubiertos por la librería.
- **Positivo**: La arquitectura escala a multi-agente si fuera necesario (subgrafos).
- **Negativo**: `langgraph` añade ~20 dependencias transitivas.
- **Negativo**: La API de LangGraph ha cambiado entre versiones (0.2 → 0.3);
  se fija `>=0.2.57` para garantizar `interrupt()` + `Command(resume=...)`.

## Guardrails implementados

- **Input guard** (`guards.py`): regex de prompt injection antes de entrar al LLM.
- **Output guard** (`guards.py`): verifica que el tier de oferta pertenezca al catálogo.
- **HITL gate** (`graph.py`): `interrupt()` cuando EV > `Settings.hitl_ev_threshold`.
